Политика конфиденциальности Tab Keeper

Действует с 10 ноября 2026 г. (обновлено 10 ноября 2026 г.)

Коротко

Tab Keeper не собирает и не передаёт ваши данные разработчику или третьим лицам. У расширения нет своих серверов, аналитики и рекламы.

Какие данные обрабатываются

  • Ваши папки, ссылки, вкладки, заметки и настройки — хранятся локально в вашем браузере.
  • Синхронизация (по желанию) — если вы её включили, расширение записывает файл синхронизации и его предыдущие версии в ваше облачное хранилище в отдельную папку: на Google Drive — «Tab Keeper — синхронизация (не удалять)» (или «Tab Keeper Sync (do not delete)», если расширение на английском), на Яндекс Диске и OneDrive — «Приложения/Tab Keeper Sync». Файл можно зашифровать вашим паролем. Пароль хранится только у вас.
  • Twitch Drops (по желанию) — чтобы показывать прогресс дропсов, расширение использует вход в Twitch, уже выполненный в вашем браузере, и запрашивает данные только у twitch.tv. Ничего не сохраняется вне вашего браузера.
  • Программа-помощник для Windows (по желанию) — работает только на вашем компьютере и только с файлами, которые вы выбрали (например, обои Wallpaper Engine).

Доступ к Google Drive

Расширение запрашивает только доступ drive.file: оно видит и изменяет только файлы, которые создало само (файлы синхронизации). Остальные файлы на вашем Диске ему недоступны. Данные из Google Drive используются только для синхронизации Tab Keeper между вашими устройствами, не передаются никому и не используются для рекламы или обучения моделей ИИ.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Яндекс Диск и OneDrive

Аналогично: расширение работает только со своей папкой в вашем хранилище и использует её только для синхронизации.

Как отключить и удалить данные

  • Выключите синхронизацию в настройках расширения и нажмите «Выйти» — расширение забудет доступ к облаку.
  • Доступ также можно отозвать в настройках аккаунта: Google — myaccount.google.com/permissions, Яндекс — id.yandex.ru, Microsoft — account.live.com/consent/Manage.
  • Файлы синхронизации можно удалить из облака вручную вместе с папкой синхронизации (названия — выше).
  • Удаление расширения удаляет все его локальные данные из браузера.

Изменения

Если политика изменится, новая версия будет опубликована на этой странице с новой датой.

Tab Keeper Privacy Policy

Effective November 10, 2026.

Tab Keeper does not collect or share your data with the developer or any third party. The extension has no servers, analytics or ads.

  • Your folders, links, tabs, notes and settings are stored locally in your browser.
  • Sync (optional): when enabled, the extension writes a sync file and its previous versions to your own cloud storage (Google Drive, Yandex Disk or OneDrive) in a dedicated folder: "Tab Keeper Sync (do not delete)" (or its Russian name) on Google Drive, "Apps/Tab Keeper Sync" on Yandex Disk and OneDrive. The file can be encrypted with your password, which stays with you.
  • Twitch Drops (optional): uses the Twitch sign-in already present in your browser and requests data only from twitch.tv. Nothing is stored outside your browser.
  • Windows helper (optional): runs only on your computer and only with files you choose.

Google Drive: the extension requests only the drive.file scope, so it can see and change only the files it created (sync files). Data from Google Drive is used solely to sync Tab Keeper between your devices; it is not shared, sold, used for advertising or for training AI models. Tab Keeper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

To stop: turn off sync and press "Sign out" in the extension, or revoke access at myaccount.google.com/permissions. You can delete the sync folder from your cloud at any time. Removing the extension deletes its local data.
